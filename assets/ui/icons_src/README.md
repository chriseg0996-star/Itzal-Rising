# Iconos fuente (Gemini)

Genera las tarjetas en Gemini (mismo estilo neón que las de recursos) y déjalas
aquí con ESTOS nombres exactos. Cuando tengas las que quieras, avísame ("listo")
y yo las recorto, les quito el fondo/número y las monto en los botones.

No tienes que generar todas — las que falten, el botón se queda solo con texto.
El número/etiqueta en la tarjeta es opcional (lo recorto igual).

## Recursos / población (YA hechos)
    pop, wood, gold, food            -> assets/ui/icons/

## Edificios (botones de construcción)

    bld_barracks.png   -> Barracks

## Unidades (botones de entrenar — por arquetipo, sirven para todas las facciones)
    unit_villager.png  -> aldeano / obrero (Villager, Ix Weaver)
    unit_soldier.png   -> soldado cuerpo a cuerpo
    unit_archer.png    -> arquero / a distancia
    unit_raider.png    -> caballería (Jaguar Rider / Stalker / Lancer)
    unit_guard.png     -> Lattice Guard (melee Ix)

Tip: una sola tarjeta por icono, glifo centrado. Si una sale con un borde del
marco de más, lo ajusto en el recorte (como pasó con "pop").
