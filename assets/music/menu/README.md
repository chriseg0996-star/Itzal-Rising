# Menu music

Drop real music files here (`.ogg`, `.mp3`, or `.wav`) and they play
automatically on the menus — shuffled, with a fade-in, advancing to the next
track when one ends. Matches stay SFX-only.

The folder ships empty: the game is silent on the menus until you add a file.
Good sources: your own Suno/AI exports, or CC0 packs (incompetech, OpenGameArt).

`.ogg` is the best fit for Godot (small, seamless). After adding files, let
Godot import them (open the editor once, or run `--headless --import`).
